## When to use
When setting up coordinates for a configuration with multiple distance constraints in 3D space.

## Strategy
- Use symmetry to simplify coordinate assignments.  
- Subtract equations to eliminate variables and find relationships.  
- Substitute systematically to reduce complexity.

## Avoid
Assuming coordinates without verifying consistency with all constraints.
